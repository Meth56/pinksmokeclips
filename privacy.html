Privacy Policy

Last updated: November 18, 2026

The PinkSmokeClips upload tool is a private tool used only by the channel owner to upload the channel's own videos to its own YouTube account.

Data accessed: the tool requests only the YouTube upload permission (youtube.upload). It does not read, collect, store, share or sell personal data of other users.

Storage: the OAuth token is stored only on the owner's computer and is used only to upload videos.

Google API Services: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: access can be revoked at any time at https://myaccount.google.com/permissions.
